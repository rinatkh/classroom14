# Короткая SQL-памятка урока

| Намерение | Форма запроса |
|---|---|
| создать таблицу | `CREATE TABLE ...` |
| добавить строку | `INSERT INTO ... VALUES ... RETURNING ...` |
| прочитать строки | `SELECT ... FROM ... WHERE ...` |
| изменить строки | `UPDATE ... SET ... WHERE ... RETURNING ...` |
| удалить строки | `DELETE FROM ... WHERE ... RETURNING ...` |
| связать таблицы | `JOIN ... ON ...` |
| начать транзакцию | `BEGIN` |
| сохранить транзакцию | `COMMIT` |
| отменить транзакцию | `ROLLBACK` |
| посмотреть план | `EXPLAIN SELECT ...` |

## Порядок чтения SELECT

Запрос пишется так:

```sql
SELECT id, title
FROM tasks
WHERE done = false
ORDER BY created_at DESC
LIMIT 10;
```

Для первого знакомства думайте о нём так:

1. `FROM` — из какой таблицы берём строки;
2. `WHERE` — какие строки оставляем;
3. `SELECT` — какие колонки показываем;
4. `ORDER BY` — как сортируем;
5. `LIMIT` — сколько строк возвращаем.

Это упрощённая модель для чтения запроса, а не полный внутренний порядок работы
PostgreSQL.

## `NULL`

`NULL` означает «значение отсутствует или неизвестно». Проверять его нужно так:

```sql
WHERE deleted_at IS NULL
WHERE deleted_at IS NOT NULL
```

Запись `deleted_at = NULL` неверна: результат сравнения будет не `true`, а
неизвестное логическое значение.
